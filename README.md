# Cash vs UPI purchase recall

A 22-slide, 10-minute presentation for Behavioral Research and Experiment Design. The active study uses one college.

Download and open [presentation.html](html-deck/presentation.html) in a current browser. All fonts, artwork, and scripts are embedded, so it works offline. GitHub shows the source; download the file to run it.

- [Presentation source, keybinds, and build instructions](html-deck/README.md)
- [Study design PDF](Cash%20vs%20UPI%20Recall%20Intern%20Field%20Experiment%20Design.pdf). This is an earlier draft. The latest operationalisation is reflected in the presentation and its presenter notes.
- `html-deck/dist/`: ready-to-serve modular website and standalone presentation.
- `skills/anatomy/`: vendored Anatomy skill and artwork toolkit, with its upstream license.
- `output/`: archived Canva-era presenter guide and review image. These describe an earlier study version and are retained as project history.

The presentation uses React, GSAP, Lenis, Motion, React Bits CountUp, and the Anatomy toolkit. Dependencies and fonts are self-hosted in `html-deck/public/`.

See [context.md](context.md) for study decisions, design rules, slide order and the editing workflow.
